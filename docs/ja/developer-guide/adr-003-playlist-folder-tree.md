# ADR-003: プレイリストのフォルダツリー

## 状態

採用

## 決定

プレイリストとフォルダは、親フォルダIDを持つ隣接リストとして保存します。親がない項目は最上位に置き、フォルダの親参照を再帰的にたどって任意の深さのツリーを表示します。同じ階層のプレイリストは`sortOrder`で並べ、ドラッグ操作による移動と並び替えを永続化します。

フォルダは内容が空の場合だけ削除できます。移動先には自身と子孫を指定できません。既存のプレイリスト保存データには親がないものとして既定値を補い、最上位へ配置します。

## 理由

M3UやMusicBee MBPは曲の順序を表しますが、このアプリ固有のフォルダ階層は表しません。階層をインポート元のパスから推測せず、ユーザーが管理する独立した構造として保存することで、音源参照先の変更や再スキャンからプレイリスト整理を分離できます。

## 影響

- プレイリストファイルのインポート時に最上位または既存フォルダを配置先として選べます。
- プレイリストの移動は音源ファイルを移動しません。
- フォルダを削除するには、先に子フォルダとプレイリストを移動または削除する必要があります。
