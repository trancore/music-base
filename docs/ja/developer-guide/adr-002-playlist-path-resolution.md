# ADR-002: プレイリストのパス解決

## 状態

採用

## 決定

手動プレイリストとM3Uは音源パスを保存し、ライブラリDBの`source_key`と正規化済み比較パスの索引を使って解決します。Windowsのドライブパスだけは区切り文字と大文字小文字を正規化し、POSIXとSMBのパスの大文字小文字は保持します。

M3Uの音源ルートが現在の参照先と異なる場合、現在のキャッシュに実在する曲へ解決できるルート置換だけをユーザーへ提示します。確認された一致はDBの実パスへ置換し、未解決パスは元の順序で保持します。

## 理由

表示用ライブラリはページングと検索条件を持つため、プレイリスト解決に使用すると結果が画面状態によって変化します。DB索引を正本にすることで、大規模ライブラリでも全件をメモリへ読み込まず、安定した照合ができます。未解決パスを保持することで、ドライブやSMB共有の再接続後に復旧できます。
