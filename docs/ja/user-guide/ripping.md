# CDリッピング

Windows版では、CDのトラックをFLACまたはMP3として音源ライブラリへ取り込めます。

MusicBrainzからアルバム候補を取得し、曲名、アーティスト、アルバム、発売年、曲順などを確認してから取り込みます。情報が見つからない場合は手動で編集します。

取り込み計画ではFLACまたはMP3、取り込み先、曲順、タグ候補を確認します。トラックはアルバム全体でも一部でも選択できます。MusicBrainzのrelease候補を選択すると、対応する曲名、アーティスト、アルバム、発売日をタグとして保存します。既存ファイルは取り込み開始前に一覧を表示して停止し、上書きしません。CDドライブの検出と実際のエンコードはWindows固有機能です。

CD import画面では、Windowsが認識しているCDドライブとメディア挿入状態を確認できます。画面表示中は定期的に状態を確認し、CDの挿入・取り出しを通知します。メディアが挿入されている場合は、トラック番号と長さを確認し、ドライブとトラックを選択できます。出力先を選び、FLACまたはMP3を指定して取り込みを開始します。複数トラックは順番に処理され、進捗表示と途中キャンセルに対応します。取り込み先が設定済みのローカルライブラリ配下の場合、正常完了後にライブラリを自動再スキャンします。

取り込み実行にはWindows環境の`ffmpeg.exe`が必要です。FLACまたはMP3へ変換し、出力先に同名ファイルがある場合は上書きしません。実行中は進捗を表示し、キャンセルすると現在のffmpeg処理を停止して次のトラックへ進みません。MusicBrainzを選択しない場合のファイル名は`Track 01.flac`または`Track 01.mp3`の形式です。
