# インターネットラジオ

「Radio」画面から、インターネットラジオ局を登録して再生できます。局名と音声ストリームURLを入力し、「Test and save」を実行してください。

虫眼鏡のアイコンからRadio Browserを検索できます。検索結果はRadio Browserが到達可能と判定した局に絞り、プレイリストやリダイレクトを解決した直接ストリームURLを使用します。局を選択すると接続テスト後に保存され、そのまま再生を開始します。

音声ストリームURLは、ラジオのWebページではなく、音声データを直接配信するURLです。たとえば、HappyHardcore.comのページURLは次のURLです。

```text
https://www.happyhardcore.com/radio/player/radio.asp
```

これは登録できません。ページ内で使用されている直接ストリームURLの例は次のとおりです。

```text
https://u1.happyhardcore.com/
```

登録済みの局は再生、編集、削除ができます。ストリームURLは配信元の都合で変更されることがあるため、再生できなくなった場合は配信元で最新URLを確認して編集してください。局の情報はこの端末の設定へ保存されます。

局一覧は「Manual order」「Name (A–Z)」「Name (Z–A)」「Genre」から並び順を選べます。Manual orderでは、局左側のハンドルをドラッグして順番を変更できます。手動順はこの端末に保存されます。
