# 再生と表示

ライブラリに登録されたFLAC／MP3ファイルを選択して再生できます。ローカルファイルに加えて、設定済みのSMB共有上にある音源も直接再生できます。再生、一時停止、停止、シーク、前後の曲への移動、音量変更、ミュートに対応しています。

「Play library」からライブラリ全体を再生キューへ追加できます。キューは現在の曲を起点に前後へ移動でき、シャッフルとリピートを切り替えられます。Playlists画面では、スキャン済みライブラリ全体を名前付きプレイリストとして保存し、後から再生・削除できます。再生エラーは画面に表示し、アプリ全体を終了させずに別の曲を選択できます。ビジュアライザとスペクトルアナライザは後続機能として追加します。

曲がキューに入っている間は、再生コントロールの下にキューを表示します。キュー内の曲を選択すると、その位置から再生を開始できます。
