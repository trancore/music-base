# 再生と表示

ライブラリに登録されたFLAC／MP3ファイルを選択して再生できます。ローカルファイルに加えて、設定済みのSMB共有上にある音源も直接再生できます。再生、一時停止、停止、シーク、前後の曲への移動、音量変更、ミュートに対応しています。

「Play library」からライブラリ全体を再生キューへ追加できます。キューは現在の曲を起点に前後へ移動でき、シャッフルとリピートを切り替えられます。Playlists画面では、スキャン済みライブラリ全体を名前付きプレイリストとして保存し、後から再生・削除できます。再生エラーは画面に表示し、アプリ全体を終了させずに別の曲を選択できます。再生コントロールには、ローカル音源から取得した波形データを表示します。SMB音源や解析できないファイルでは、再生位置に同期したフォールバック表示を使います。これは波形表示であり、実際の周波数スペクトル解析ではありません。

Androidでは、再生セッションから取得したFFTデータによるリアルタイムスペクトル表示を利用できます。端末や再生セッションが対応していない場合は、波形または再生位置ベースの表示へフォールバックします。Windowsでは現在、波形または再生位置ベースの表示を使います。

曲がキューに入っている間は、再生コントロールの下にキューを表示します。キュー内の曲を選択すると、その位置から再生を開始できます。

Androidではバックグラウンド再生に対応し、メディア通知とロック画面から再生・一時停止、前の曲、次の曲を操作できます。操作を利用するには、Androidアプリを一度起動してください。
