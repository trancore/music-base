# 再生と表示

ライブラリに登録されたFLAC／MP3ファイルを選択して再生できます。ローカルファイルに加えて、設定済みのSMB共有上にある音源も直接再生できます。再生、一時停止、停止、シーク、前後の曲への移動、音量変更、ミュートに対応しています。

インターネットラジオは、Radio画面で登録した音声ストリームURLから再生できます。ライブ配信には総再生時間がないため、再生ドックには再生開始からの経過時間を表示します。ラジオ再生中はシーク、曲送り、シャッフルを使用できません。

「Play library」からライブラリ全体を再生キューへ追加できます。楽曲をダブルクリックすると、その楽曲を再生します。再生中のドックは画面上部に固定され、どの画面からでも操作できます。キューは現在の曲を起点に前後へ移動でき、シャッフルとリピートを切り替えられます。Playlists画面の最上位には、フォルダとプレイリストを配置できます。フォルダは任意の深さまで入れ子にして作成・名前変更・移動・削除でき、内容があるフォルダは削除できません。プレイリストをドラッグすると、同じ階層で並び替えたり、別のフォルダや最上位へ移動したりできます。各プレイリストを展開すると収録曲の一覧を確認でき、複数を同時に展開できます。通常のプレイリストでは、タイトル、アーティスト、アルバム、音源パスでライブラリを絞り込み、曲を選択して再生順を並び替えられます。オートプレイリストでは同じ項目を対象とする検索語を保存し、現在のライブラリに一致する曲を表示・再生します。編集画面では、条件を入力しながら一致件数と曲のプレビューを確認できます。ライブラリを再スキャンすると結果も自動的に変わります。

「Import M3U playlist」からUTF-8の`.m3u`または`.m3u8`ファイルを読み込めます。インポート先として最上位または既存のフォルダを選べます。`#EXTM3U`と`#EXTINF`を含む拡張M3U、絶対パス、プレイリストファイルからの相対パスに対応します。インポート前に、完全一致した曲数と利用できない曲数を確認できます。M3Uの音源ルートが現在のライブラリと異なる場合は、実在する曲から検証したルート変換候補を選択できます。読み込んだ順序を保持し、現在のライブラリに存在しないパスも「unavailable」として保存するため、音源の切り替えや再スキャン後に復旧できます。ファイル名を初期プレイリスト名として使用し、音源ファイル自体は移動・変更しません。

再生エラーは画面に表示し、アプリ全体を終了させずに別の曲を選択できます。再生ドックには、対応プラットフォームではリアルタイムスペクトル、その他の環境ではローカル音源の波形データを表示します。SMB音源や解析できないファイルでは、再生位置に同期したフォールバック表示を使います。

Androidでは再生セッション、Windowsではこのアプリのプロセスループバック、macOS 14.2以降ではこのアプリだけに限定した音声キャプチャから、リアルタイムスペクトルを表示します。ほかのアプリやシステム全体の音声は解析しません。音声キャプチャを拒否した場合や対応APIが利用できない場合は、波形または再生位置ベースの表示へフォールバックします。

デスクトップ版では、曲がキューに入っている間はサイドメニュー下部にキューを表示します。キュー内の曲を選択すると、その位置から再生を開始できます。

Androidではバックグラウンド再生に対応し、メディア通知とロック画面から再生・一時停止、前の曲、次の曲を操作できます。操作を利用するには、Androidアプリを一度起動してください。

## Waveform / spectrum visualizer

再生中の曲に対して、対数周波数帯域へ集約したスペクトルをバーで表示します。デスクトップ版では2048サンプルのFFTにHann窓を適用し、20Hz〜20kHzを128帯域へ分け、振幅をdBへ変換してから時間方向に平滑化します。Androidでは再生セッションが提供するFFTを同じ表示形式へ変換します。解析やリアルタイム取得が利用できない場合は、再生位置とアニメーションによるフォールバック表示を使います。処理はメモリ上だけで行い、録音ファイルは作成しません。

デスクトップ版では、再生キューをサイドメニュー下部に表示します。キュー内の曲を選択すると、その曲から再生できます。モバイル版では再生ドックを中心に操作します。

曲名、アーティスト、アルバム、音源パスでライブラリを検索してから再生できます。

再生エラーは画面に表示し、アプリ全体を終了させずに別の曲を選択できます。
