# セットアップ

## 音源参照先

音源参照先は、ローカルディレクトリまたはユーザー・管理者が用意したSMB共有から選択します。具体的なパスは利用環境によって異なります。

```text
ローカルディレクトリの例：`D:\Music`
SMB共有の例：`\\<server>\<share>\[subfolder]`
```

参照先は設定画面から変更できます。ローカルディレクトリを選択するか、SMBホスト、共有名、必要に応じてサブフォルダを指定してください。SMB設定ではユーザー名とパスワードを入力し、「接続テストと保存」を実行します。

## 接続情報

SMB共有で認証が必要な場合は、ユーザー名とパスワードを入力します。パスワードは対応プラットフォームの安全な資格情報ストレージへ保存し、ログやソースコードへ出力しません。接続テストに失敗した場合は、ホスト、共有名、認証情報、ネットワーク接続を確認してください。

## Androidについて

Android版でも同じSMB設定モデルを使用する予定です。現在のSMB機能は接続テスト、設定保存、ライブラリスキャンに対応しています。SMB上の曲の直接再生とCDリッピングは後続機能です。CDリッピングはWindows版の機能です。
