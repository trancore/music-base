# セットアップ

## 音源参照先

音源参照先は、ローカルディレクトリまたはユーザー・管理者が用意したSMB共有から選択します。具体的なパスは利用環境によって異なります。

```text
ローカルディレクトリの例：`D:\Music`
SMB共有の例：`\\<server>\<share>\[subfolder]`
```

参照先はSettings画面から変更できます。ローカルライブラリ欄でディレクトリを選択するか、SMBホスト、共有名、必要に応じてサブフォルダを指定してください。SMB設定ではユーザー名とパスワードを入力し、「接続テストと保存」を実行します。保存済みのSMB設定は「保存済みSMB設定をクリア」から削除できます。Library画面から再スキャンを実行できます。

## 接続情報

SMB共有で認証が必要な場合は、ユーザー名とパスワードを入力します。パスワードは対応プラットフォームの安全な資格情報ストレージへ保存し、ログやソースコードへ出力しません。接続テストに失敗した場合は、ホスト、共有名、認証情報、ネットワーク接続を確認してください。

## macOSについて

macOS版では、ローカルおよびSMBライブラリ、再生、プレイリスト、メタデータ、ビジュアライザを利用できます。macOS 14.2以降が必要です。ローカルフォルダを初めて選択するとアクセスを許可し、再起動後も再スキャンできるようsecurity-scoped bookmarkを保存します。SMB再生にはネットワークアクセス、リアルタイムスペクトラムには音声キャプチャ許可が必要です。

macOS版ではCDリッピングを利用できません。

## Androidについて

Androidランナーを追加し、同じFlutterアプリシェルを利用できる状態にしました。現在のSMB機能は接続テスト、設定保存、ライブラリスキャン、SMB上の曲の直接再生に対応しています。CDリッピングはWindows版専用です。
