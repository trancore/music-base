# セットアップ

アプリのSettings画面にある「Help」から「User guide」を選ぶと、この利用者向けドキュメントを既定のブラウザで開けます。利用にはインターネット接続が必要です。

## 言語

Settingsの「Appearance」にある「Language」から表示言語を選択できます。「System」はOSの言語に従い、「English」と「日本語」では言語を固定します。「Library」「Playlists」「Settings」など、短いナビゲーション名や製品らしさを重視する見出しは、統一感のため英語のまま表示します。

## 音源参照先

音源参照先は、ローカルディレクトリまたはユーザー・管理者が用意したSMB共有から選択します。具体的なパスは利用環境によって異なります。

```text
ローカルディレクトリの例：`D:\Music`
SMB共有の例：`\\<server>\<share>\[subfolder]`
```

参照先はSettings画面から変更できます。ローカルライブラリ欄でディレクトリを選択するか、SMBホスト、共有名、必要に応じてサブフォルダを指定してください。SMB設定ではユーザー名とパスワードを入力し、「Connect, save, and scan」を実行します。接続確認と保存が成功すると、そのまま対応する音声ファイル（FLAC、MP3、OGG、3GP、MP4）のスキャンが開始されます。保存済みのSMB設定を再スキャンする場合は「Scan library」を実行してください。保存した設定は「保存済みSMB設定をクリア」から削除できます。

## 接続情報

SMB共有で認証が必要な場合は、ユーザー名とパスワードを入力します。パスワードは対応プラットフォームの安全な資格情報ストレージへ保存し、ログやソースコードへ出力しません。「Test connection and save」に成功すると、設定を保存したあと指定したサブフォルダを自動スキャンします。接続テストに失敗した場合は、ホスト、共有名、認証情報、ネットワーク接続を確認してください。

## macOSについて

macOS版では、ローカルおよびSMBライブラリ、再生、プレイリスト、メタデータ、ビジュアライザを利用できます。macOS 14.2以降が必要です。ローカルフォルダを初めて選択するとアクセスを許可し、再起動後も再スキャンできるようsecurity-scoped bookmarkを保存します。SMB再生にはネットワークアクセスが必要です。初回接続時にローカルネットワークへのアクセスを求められた場合は許可してください。拒否した場合は「システム設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」からMusic Baseを許可します。リアルタイムスペクトラムには音声キャプチャ許可が必要です。

macOS版ではCDリッピングを利用できません。

## Androidについて

Androidランナーを追加し、同じFlutterアプリシェルを利用できる状態にしました。現在のSMB機能は接続テスト、設定保存、ライブラリスキャン、SMB上の曲の直接再生に対応しています。CDリッピングはWindows版専用です。
