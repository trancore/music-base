# 音源ライブラリ

設定画面からローカル音源ディレクトリを選択すると、アプリはその配下を再帰的にスキャンします。現在はFLACとMP3を対象とし、検出したファイル名を曲名としてライブラリへ表示します。

検出した曲のパスと基本情報はローカルDBへキャッシュします。音源ファイル自体の正本は選択した参照先にあり、DBへ音源本体をコピーすることはありません。

参照先が利用できない場合やスキャンに失敗した場合は、エラーを表示して再試行できる状態を維持します。接続テスト済みのSMB共有は、ホーム画面からスキャンを実行できます。SMB上の曲は現在一覧表示まで対応し、直接再生は後続機能です。

参照先が一時的に利用できない場合、キャッシュ済みの情報は表示できますが、再生には参照先への接続またはアクセスが必要です。
