# 音源ライブラリ

設定画面からローカル音源ディレクトリを選択すると、アプリはその配下を再帰的にスキャンします。現在はFLACとMP3を対象としています。埋め込みのMP3 ID3タグとFLAC Vorbisコメントを優先し、タグを読み取れない場合は`Artist/Album/01 - Title.flac`のような一般的な構成からアーティスト、アルバム、曲名を推定します。それ以外のファイルはファイル名を曲名として表示します。

検出した曲のパスと基本情報はローカルDBへキャッシュします。音源ファイル自体の正本は選択した参照先にあり、DBへ音源本体をコピーすることはありません。

ホーム画面の検索欄では、キャッシュ済みの曲を曲名、アーティスト、アルバム、音源パスで大文字・小文字を区別せず検索でき、入力中に結果が更新されます。

アーティスト名やアルバム名を推定できた場合は、ライブラリ一覧で曲名の下に表示します。音源の参照パスも補助情報として表示します。

参照先が利用できない場合やスキャンに失敗した場合は、エラーを表示して再試行できる状態を維持します。接続テスト済みのSMB共有は、ホーム画面からスキャンを実行できます。SMB上の曲はレンジ読み込みで直接再生できます。

参照先が一時的に利用できない場合、キャッシュ済みの情報は表示できますが、再生には参照先への接続またはアクセスが必要です。
