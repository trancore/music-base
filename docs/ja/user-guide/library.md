# 音源ライブラリ

設定画面からローカル音源ディレクトリを選択すると、アプリはその配下を再帰的にスキャンします。現在はFLACとMP3を対象としています。埋め込みのMP3 ID3タグとFLAC Vorbisコメントを優先し、タグを読み取れない場合は`Artist/Album/01 - Title.flac`のような一般的な構成からアーティスト、アルバム、曲名を推定します。それ以外のファイルはファイル名を曲名として表示します。

検出した曲のパスと基本情報はローカルDBへキャッシュします。音源ファイル自体の正本は選択した参照先にあり、DBへ音源本体をコピーすることはありません。

保存済みキャッシュは起動時にすぐ表示され、その後バックグラウンドで差分更新されます。最大10万曲を想定し、一覧は200曲ずつスクロールに応じて読み込みます。検索は空白区切りの単語をすべて含む前方一致です。画像は重複を除いて保存し、画面に表示される曲だけ読み込みます。

Settingsから手動で再スキャンした場合も、現在のキャッシュを表示したままバックグラウンドで更新します。スキャン中も検索、閲覧、キャッシュ済み楽曲の選択を続けられます。成功後に一覧と画像を更新し、失敗時は直前のキャッシュを残してエラーを表示します。

SMB参照先を更新できない場合は、直近に選択したローカル参照先をその起動中の代替として使用します。どちらも利用できない場合は「Library not found」と表示します。次回起動時には主参照先のSMBへ再接続します。

ホーム画面の「Search library」欄から、曲名、アーティスト名、アルバム名、ファイルパスでキャッシュ済みの曲を絞り込めます。大文字・小文字を区別せず、入力中に結果が更新されます。楽曲一覧はTable形式で、Title、Artist、Album、Sourceのヘッダーをクリックすると昇順／降順を切り替えられます。楽曲をダブルクリックすると、その楽曲を再生します。

ホーム画面上部の「Songs」「Albums」「Artists」で表示単位を切り替えられます。アルバムとアーティストはカード形式で表示され、カードを選ぶと所属する曲だけをページ単位で表示します。カードの再生ボタンから、そのアルバムまたはアーティストの全曲を再生できます。検索欄は表示中の単位に合わせて、曲、アルバム名、アーティスト名を絞り込みます。

ライブラリの見出し、検索欄、Tableヘッダーは画面上部に固定されます。楽曲が多い場合は、Table内の楽曲行だけをスクロールできます。

アーティスト名やアルバム名を推定できた場合は、ライブラリTableに表示します。音源の参照パスも補助情報として表示します。アルバムアートがない場合も、アートワーク列の幅は変わりません。

埋め込みアルバムアートは2MB以下の場合にライブラリ情報とともにキャッシュし、サムネイルとして表示します。大きすぎる画像や読み取れない画像はスキップします。

ローカルおよびSMB上のFLACでは、埋め込みアートワークとディスク番号・トラック番号を読み取ります。SMBでは音源全体をコピーせず、FLACのメタデータブロックだけをレンジ読み込みします。埋め込み画像がない場合は、同じフォルダの`cover.jpg`、`cover.jpeg`、`cover.png`、`folder.jpg`を使用します。アルバム内はディスク番号、トラック番号、音源パスの順で表示・再生します。番号がない曲は番号付きの曲より後に表示します。

曲一覧の先頭列にはトラック番号を表示します。複数ディスクの2枚目以降は、ディスク番号とトラック番号を`2-7`の形式で表示します。再スキャン結果は全走査に成功してからキャッシュへ反映するため、スキャン中や接続失敗時も直前のキャッシュを参照できます。

参照先が利用できない場合やスキャンに失敗した場合は、エラーと「Retry」ボタンを表示します。参照先を確認した後、ホーム画面から再試行できます。接続テスト済みのSMB共有は、Settingsから保存・接続確認し、Library画面からスキャンできます。SMB上の曲はレンジ読み込みで直接再生できます。

参照先が一時的に利用できない場合、キャッシュ済みの情報は表示できますが、再生には参照先への接続またはアクセスが必要です。
