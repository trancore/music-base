# MusicBrainz search

On the Metadata screen, enter an artist or album name to search MusicBrainz for release candidates. Each candidate shows the album title, artist, release date, country, and track count.

Search results are cached in the app. Searches may wait briefly when requests are made close together to respect MusicBrainz usage limits. Candidate selection and tag writing during CD import will be added in a later feature.
