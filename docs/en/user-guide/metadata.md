# MusicBrainz search

On the Metadata screen, enter an artist or album name to search MusicBrainz for release candidates. Each candidate shows the album title, artist, release date, country, and track count.

Search results are cached in the app. Select a candidate to load release details, including per-disc track order, titles, and durations. Searches may wait briefly when requests are made close together to respect MusicBrainz usage limits. Candidate selection for CD import and tag writing will be added in a later feature.
