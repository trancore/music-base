# MusicBrainz during CD import

MusicBrainz search is available inside the Windows CD import screen, rather than as a standalone Metadata screen. Enter an artist or album name to search for release candidates.

Search results are cached in the app. Select a candidate to review its track order and titles; the selected release's track titles, artist, album, and release date are written into imported file tags. If no release is found, you can continue with manually entered metadata.
