# Troubleshooting

## Cannot access the music library

For a local directory, check the path and access permissions. For an SMB share, check the server name, share name, username, and password. Also verify that the same share can be opened from Windows Explorer.

## A track cannot be found

Check the configured library location and run a new scan. Confirm that the file was not moved or deleted.

## MusicBrainz metadata cannot be retrieved

Check the network connection and retry. You can enter the tags manually when no match is available.
