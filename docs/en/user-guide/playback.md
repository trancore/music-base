# Playback and display

Select a FLAC or MP3 file from the library to play it. In addition to local files, tracks on the configured SMB share can be played directly. The current implementation supports play, pause, stop, seeking, previous/next track, volume control, and mute.

Use “Play library” to add the whole library to the playback queue. The queue supports previous/next navigation, shuffle, and repeat. Playback errors are shown in the UI so another track can be selected without closing the app. Playlists, the visualizer, and the spectrum analyzer will be added in later features.
