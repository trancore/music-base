# Development setup

Prepare the Flutter SDK, Windows or macOS desktop tooling, Android tooling, and Node.js.

```text
flutter pub get
pnpm install
flutter analyze
flutter test
pnpm docs:build
```

Start the documentation development server with `pnpm docs:dev`.
For macOS development, use macOS 14.2 or later. Run `flutter pub get`, then validate the desktop target with `flutter build macos`. App Store signing is outside the current scope; configure a signed Xcode build before distributing the app.

To run on a physical Android device, enable Developer options and USB debugging, connect the device, and confirm it is listed by `flutter devices`. In Zed, run the `Run Music Base (Android: physical device)` task to select the connected Android device and launch the app.

## Desktop distribution artifacts

Windows and macOS distribution artifacts are generated by GitHub Actions when a Git tag beginning with `v` is pushed to `main`, then attached to a GitHub Release.

- Windows: `MusicBase-Setup.exe`. The installer lets users choose Start Menu and desktop shortcuts independently.
- macOS: `MusicBase.dmg`. Copy the app from the DMG to Applications. Signing and notarization are not configured yet, so this is intended for test distribution.

Android devices are not installed from the Release. Connect a device with USB debugging enabled and use the `Run Music Base (Android: physical device)` Zed task for local installation and launch.
